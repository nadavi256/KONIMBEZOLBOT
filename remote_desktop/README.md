# שליטה מרחוק – חלופה ל-AnyDesk / TeamViewer

מערכת שליטה מרחוק במחשבים, שעובדת כמו AnyDesk: למחשב המרוחק יש **מזהה קבוע וסיסמה**,
ומתחברים אליו **מכל דפדפן** בלי להתקין כלום בצד השולט.

```
 דפדפן (השולט)  <──wss──>  server.py (שרת ממסר)  <──wss──>  host.py (המחשב הנשלט)
```

שני הצדדים מתחברים **החוצה** לשרת, כך שאין צורך לפתוח פורטים בראוטר של אף אחד.

## הרכיבים

| קובץ | איפה רץ | תפקיד |
|------|---------|-------|
| `server.py` | שרת/VPS עם כתובת ציבורית | ממסר בין השולט למחשב הנשלט + מגיש את דף הצפייה |
| `host.py` | המחשב שרוצים לשלוט בו | צילום מסך, הזרמה, והפעלת עכבר/מקלדת |
| `static/viewer.html` | בדפדפן של השולט | הצגת המסך ושליחת עכבר/מקלדת |

## הפעלה מהירה

### 1. השרת (פעם אחת, על VPS)
```bash
pip install -r requirements-server.txt
```
```bash
python server.py --port 8080
```
או עם Docker:
```bash
docker build -t remote-relay . && docker run -d -p 8080:8080 remote-relay
```

**חובה בשימוש דרך האינטרנט: HTTPS.** הדרך הפשוטה היא לשים את השרת מאחורי Caddy,
שמוציא תעודת SSL אוטומטית:
```bash
caddy reverse-proxy --from remote.your-domain.com --to localhost:8080
```
או ישירות עם תעודה:
```bash
python server.py --port 443 --cert fullchain.pem --key privkey.pem
```

כדי שרק המחשבים שלכם יוכלו להירשם לשרת, הוסיפו מפתח גישה:
```bash
python server.py --port 8080 --access-key SOME-LONG-SECRET
```

### 2. המחשב הנשלט
```bash
pip install -r requirements-host.txt
```
```bash
python host.py --server wss://remote.your-domain.com
```
נפתח חלון קטן שמציג **מזהה** (קבוע, נשמר ב-`~/.remote_desktop_host.json`) ו**סיסמה** (חדשה בכל הפעלה).
כשמישהו מתחבר, מופיעה בקשת אישור, ובזמן החיבור החלון מראה שהמחשב נשלט, עם כפתור "סיים חיבור".

אפשרויות:
| דגל | משמעות |
|-----|--------|
| `--password XXXXXXXX` | סיסמה קבועה (לפחות 8 תווים) במקום סיסמה אקראית |
| `--no-confirm` | גישה ללא השגחה, בלי לאשר כל חיבור (מחייב `--password`, רק למחשבים שלכם) |
| `--view-only` | צפייה בלבד, בלי שליטה |
| `--monitor 2` | מסך שני |
| `--access-key ...` | אם השרת דורש מפתח גישה |
| `--console` | בלי חלון, הכל בטרמינל |

### 3. השולט
פותחים בדפדפן את `https://remote.your-domain.com`, מקלידים מזהה וסיסמה ומתחברים.
אפשר גם קישור ישיר עם המזהה: `https://remote.your-domain.com/?id=123456789`

בסרגל העליון: ניתוק, מסך מלא, איכות (גבוהה / בינונית / חיבור איטי) ותיבה לשליחת טקסט
(שימושי לעברית או להדבקה כשפריסת המקלדת בשני הצדדים שונה).

## הפיכה לקובץ EXE (Windows)
כדי לתת ללקוח קובץ אחד להפעלה, בלי להתקין Python:
```bash
pip install pyinstaller
```
```bash
pyinstaller --onefile --noconsole --name RemoteHost host.py
```
כדי שהלקוח לא יצטרך להקליד את כתובת השרת, אפשר לשנות את ברירת המחדל של `--server` בקוד לפני הבנייה.

## אבטחה – מה כבר יש
- כל חיבור דורש סיסמה, ובברירת מחדל גם **אישור ידני** בצד הנשלט.
- החלון בצד הנשלט מראה בבירור שהמחשב בשליטה ומאפשר לנתק בכל רגע.
- אחרי 5 סיסמאות שגויות המזהה ננעל ל-5 דקות.
- רק שולט אחד בכל פעם.
- השוואת סיסמאות בזמן קבוע ומפתח גישה אופציונלי לרישום מחשבים.

## מגבלות ידועות / המשך פיתוח
- **הצפנה**: ההצפנה היא TLS בין כל צד לשרת. השרת עצמו רואה את התעבורה, ולכן הוא צריך להיות שרת שלכם.
  שלב הבא: הצפנה מקצה לקצה או WebRTC ישיר בין הצדדים.
- **ביצועים**: המסך נשלח כתמונות JPEG (נשלחות רק כשהמסך משתנה, עם בקרת קצב). זה טוב לתמיכה טכנית ועבודה משרדית;
  לווידאו חלק צריך מקודד H.264 / WebRTC.
- **Ctrl+Alt+Del ומסך UAC ב-Windows** לא נשלטים מתהליך רגיל. בשביל זה צריך להריץ את המארח כשירות מערכת (Windows Service).
- **macOS**: צריך לאשר ל-Python/לאפליקציה הרשאות "הקלטת מסך" ו"נגישות" בהגדרות המערכת.
- **Linux**: חלק מהתווים שאינם באנגלית (למשל עברית) שנשלחים דרך תיבת הטקסט עלולים להשתבש (מגבלה של pynput ב-X11).
  ב-Windows זה עובד תקין. ב-Wayland השליטה דורשת הגדרות נוספות.
- עוד אין: העברת קבצים, סנכרון לוח (clipboard), שמע, רשימת מחשבים שמורים.
