🖥️ תמיכה מרחוק

חיבור מאובטח למחשב שלך, רק באישור שלך

צריכים תמיכה?

  1. הורידו את הקובץ ופתחו אותו
  2. הקריאו לטכנאי את המזהה ואת הסיסמה
  3. אשרו את בקשת החיבור
⬇ הורדת תוכנת התמיכה

טכנאי

  1. פתחו את תוכנת השליטה
  2. הקלידו את המזהה והסיסמה של הלקוח
  3. לחצו "התחבר"
⬇ הורדת תוכנת השליטה או התחברו ישירות מהדפדפן ←

אם מופיעה ההודעה "Windows protected your PC", לחצו על More info ואז על Run anyway.
אפשר לנתק את החיבור בכל רגע מהחלון של תוכנת התמיכה.
