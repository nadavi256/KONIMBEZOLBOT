# 🧠 המוח של פיפו: שרת המאמן

השרת שמפעיל את חיית המחמד-מאמן [`pet/`](../pet/README.md), ואם רוצים גם בוט טלגרם עם אותו זיכרון.

```
┌──────── המכשיר (pet/) ────────┐        ┌──────────── השרת (coach/) ────────────┐
│ פיפו מונפש · צעדים · כפתורים  │  WiFi  │ ElevenLabs: דיבור → טקסט (עברית)       │
│ מקליט ← שולח ← מנגן ומציג     │ ─────► │ Claude: פיפו = מאמן + זיכרון + כלים    │
└───────────────────────────────┘        │ ElevenLabs: טקסט → קול עברי            │
                                          │ בועות דיבור בעברית · ניסיון ושלבים      │
                        טלגרם (רשות) ◄──► │ תזכורות · צ'ק-אין · "ישבת מדי, בוא נזוז" │
                                          └────────────────────────────────────────┘
```

## מה צריך
| מה | מחיר משוער |
|---|---|
| **M5Stack StickS3**: המכשיר | בערך $21.50 |
| מפתח **Anthropic API** (Claude) | לפי שימוש |
| **ElevenLabs** (מסלול בתשלום): זיהוי דיבור וקול עברי | לפי מסלול |
| שרת 24/7 (Railway, Render או VPS) | בערך $5 לחודש |

## הפעלה
```bash
cd coach
pip install -r requirements.txt
cp .env.example .env      # ANTHROPIC_API_KEY, ELEVENLABS_API_KEY, DEVICE_KEY
python server.py          # פורט 8080
```
בשרת צריך פונט שכולל עברית (DejaVu). ב-Docker הוא כבר מותקן.

### Docker / Railway
```bash
docker build -t coach coach/
docker run -d --restart=always --env-file coach/.env -p 8080:8080 -v coach_data:/data coach
```
ב-Railway: מגדירים את `coach/` כתיקיית השירות (Root Directory), מכניסים את המשתנים ומחברים Volume לנתיב `/data`.
את הכתובת שמתקבלת רושמים ב-`SERVER_URL` במכשיר.

### טלגרם (רשות)
ממלאים `COACH_BOT_TOKEN`, שולחים לבוט `/start`, ורושמים את המספר שהוא מחזיר ב-`OWNER_CHAT_ID`.
אחרי זה פיפו כותב לך גם בטלגרם, ואפשר לשלוח לו תמונה של אוכל ולקבל הערכת קלוריות.

## קבצים
- `server.py`: ה-API של המכשיר, תזכורות, צ'ק-אינים, תזכורות לזוז, והפעלת טלגרם
- `brain.py`: Claude, האישיות של פיפו והכלים (זיכרון, רישום, תזכורות)
- `pet.py`: ניסיון, שלבי גדילה ומצב רוח
- `voice.py`: ElevenLabs, דיבור לטקסט וטקסט לדיבור
- `screens.py`: ציור בועות דיבור וכרטיס מצב בעברית
- `storage.py`: שמירה לקובץ JSON
- `coach_bot.py`: טלגרם
