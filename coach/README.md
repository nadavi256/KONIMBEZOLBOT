# 🏋️ מאמן אישי צמוד — בוט טלגרם פרטי

בוט טלגרם שרק אתה יכול לדבר איתו. הוא מאמן כושר, מאמן תזונה ועוזר אישי, והוא רץ על Claude.

## מה הוא עושה
- **מכיר אותך**: בשיחה הראשונה הוא שואל על המטרה, הגובה והמשקל, הציוד, פציעות וזמן פנוי, וזוכר את זה לתמיד (`/profile`).
- **תוכנית אימונים** מותאמת אישית, שמתקדמת לפי הדיווחים שלך.
- **רישום**: "עשיתי 3 סטים של סקוואט 60 ק"ג", "שקלתי 82.4", "ישנתי 6 שעות". הכול נשמר.
- **תמונת אוכל**: אתה שולח צילום של הצלחת ומקבל הערכה של קלוריות וחלבון.
- **צ'ק-אין יומי**: הודעה ב-07:30 עם התוכנית להיום, וב-21:00 סיכום ושאלה על מה שחסר.
- **תזכורות**: "תזכיר לי מחר ב-18:00 ללכת לחדר כושר".
- **סיכומים**: "איך הלך לי השבוע?"

## מה צריך להזמין / לפתוח
| מה | איפה | מחיר |
|---|---|---|
| בוט טלגרם חדש | ב-[@BotFather](https://t.me/BotFather): `/newbot` ← מקבלים token | חינם |
| מפתח API של Claude | [console.anthropic.com](https://console.anthropic.com) ← Billing ← API Keys | לפי שימוש. בערך $3–10 לחודש בשימוש אישי יומיומי |
| שרת שרץ 24/7 | [Railway](https://railway.app) או [Render](https://render.com) (עם דיסק קבוע), או VPS קטן (Hetzner / DigitalOcean) | בערך $5 לחודש |

> GitHub Actions לא מתאים לבוט הזה, כי הוא צריך לרוץ כל הזמן כדי לענות לך מיד ולשלוח תזכורות.

## הפעלה
```bash
cd coach
pip install -r requirements.txt
cp .env.example .env        # למלא COACH_BOT_TOKEN ו-ANTHROPIC_API_KEY
python coach_bot.py
```
1. שולחים לבוט `/start` והוא עונה עם ה-Chat ID שלך.
2. רושמים את המספר ב-`OWNER_CHAT_ID` בקובץ `.env` ומפעילים את הבוט מחדש.
3. שולחים שוב `/start` ומתחילים.

### Docker / Railway
```bash
docker build -t coach coach/
docker run -d --restart=always --env-file coach/.env -v coach_data:/data coach
```
ב-Railway: מגדירים את `coach/` כתיקיית השירות (Root Directory), מכניסים את המשתנים מ-`.env.example`, ומחברים Volume לנתיב `/data`, כדי שהזיכרון יישמר גם אחרי הפעלה מחדש.

## פקודות
- `/profile`: מה הבוט זוכר עליך
- `/reset`: מנקה את השיחה האחרונה (הפרופיל והרישומים נשמרים)

## קבצים
- `coach_bot.py`: הטלגרם: הודעות, תמונות, צ'ק-אינים ותזכורות
- `brain.py`: Claude, הפרומפט של המאמן והכלים (זיכרון, רישום, תזכורות)
- `storage.py`: שמירה לקובץ JSON בתיקייה `data/`
