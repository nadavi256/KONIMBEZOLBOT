# 🏋️ מאמן אישי צמוד: שעון חכם שמדבר איתך

שעון על היד עם מסך, מיקרופון ורמקול. הוא סופר צעדים ומדבר איתך בעברית בתור מאמן אישי.
מחזיקים אצבע על המסך, שואלים, והמאמן עונה בקול ומציג את התשובה על המסך.
המאמן זוכר אותך, רושם אימונים, אוכל ומשקל, שולח צ'ק-אין בבוקר ובערב ומזכיר דברים.
אפשר גם לדבר איתו בכתב בטלגרם, וזה אותו מאמן עם אותו זיכרון.

```
┌──────────── השעון (watch/) ────────────┐        ┌──────── השרת (coach/) ────────┐
│ צעדים (BMA423) · מיקרופון · רמקול · מסך │  WiFi  │ ElevenLabs: דיבור → טקסט       │
│ מקליט ← שולח ← מנגן ומציג               │ ─────► │ Claude: המאמן + זיכרון + כלים  │
└────────────────────────────────────────┘        │ ElevenLabs: טקסט → קול עברי    │
                                                   │ מצייר מסכים בעברית             │
                                 טלגרם (רשות) ◄──► │ תזכורות + צ'ק-אין יומי          │
                                                   └────────────────────────────────┘
```

## מה להזמין
| מה | למה | מחיר משוער |
|---|---|---|
| **LILYGO T-Watch S3 Plus** (מהחנות של LILYGO או מ-AliExpress) | השעון: ESP32-S3, מסך מגע 1.54", מיקרופון, רמקול, חיישן צעדים, רטט, סוללה 940mAh ו-GPS | בערך $59–75 |
| כבל Micro-USB שמעביר נתונים | לצריבה ולטעינה | בדרך כלל יש בבית |
| מפתח **Anthropic API** | המוח (Claude) | לפי שימוש |
| חשבון **ElevenLabs** (מסלול בתשלום) | זיהוי דיבור בעברית וקול עברי טבעי | בערך $5–22 לחודש לפי מסלול |
| שרת שרץ 24/7: Railway, Render או VPS | מריץ את `server.py` | בערך $5 לחודש |

> גם ה-T-Watch S3 הרגיל (בלי Plus, זול יותר) עובד עם אותה קושחה, אבל יש לו סוללה קטנה יותר ואין לו GPS.

## הפעלת השרת
```bash
cd coach
pip install -r requirements.txt
cp .env.example .env      # למלא ANTHROPIC_API_KEY, ELEVENLABS_API_KEY, DEVICE_KEY
python server.py          # מאזין על פורט 8080
```
בשרת צריך פונט שכולל עברית (DejaVu). ב-Docker הוא כבר מותקן.

### Docker / Railway
```bash
docker build -t coach coach/
docker run -d --restart=always --env-file coach/.env -p 8080:8080 -v coach_data:/data coach
```
ב-Railway: מגדירים את `coach/` כתיקיית השירות (Root Directory), מכניסים את המשתנים ומחברים Volume לנתיב `/data`.
את הכתובת שמתקבלת (`https://...up.railway.app`) רושמים ב-`SERVER_URL` בשעון.

### טלגרם (רשות)
ממלאים `COACH_BOT_TOKEN`, שולחים לבוט `/start`, ורושמים את המספר שהוא מחזיר ב-`OWNER_CHAT_ID`.
שם אפשר גם לשלוח תמונה של אוכל ולקבל הערכת קלוריות.

## קבצים
- `server.py`: ה-API של השעון, תזכורות, צ'ק-אינים, והפעלת טלגרם
- `brain.py`: Claude, הפרומפט של המאמן והכלים (זיכרון, רישום, תזכורות)
- `voice.py`: ElevenLabs, דיבור לטקסט וטקסט לדיבור
- `screens.py`: ציור מסכי השעון בעברית (240×240)
- `storage.py`: שמירה לקובץ JSON
- `coach_bot.py`: טלגרם
