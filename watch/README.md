# ⌚ קושחה לשעון — LILYGO T-Watch S3 / S3 Plus

השעון הוא "לקוח רזה": הוא סופר צעדים, מקליט את הקול שלך, מציג מסכים ומשמיע דיבור.
כל העבודה הכבדה (זיהוי דיבור, Claude, הקראה ועיבוד מסכים בעברית) נעשית בשרת `coach/server.py`.

## שימוש
- **החזקת אצבע על המסך**: מדברים עם המאמן. עוזבים כדי לשלוח (עיגול אדום = מקליט, כחול = חושב).
- **נגיעה קצרה**: עמוד הבא בתשובה, או חזרה למסך הבית.
- **הכפתור בצד**: מדליק את המסך, חוזר הביתה, או עוצר הקראה.
- **רטט**: למאמן יש משהו בשבילך (תזכורת או צ'ק-אין בוקר/ערב), והוא יקריא אותו מיד.
- **מסך הבית**: שעה, צעדים, טבעת התקדמות ליעד היומי וסוללה. בלי חיבור מוצג פס צעדים ונקודה אדומה.

## צריבה
1. מתקינים [VS Code](https://code.visualstudio.com/) ואת התוסף **PlatformIO**.
2. פותחים את התיקייה `watch/`.
3. מעתיקים את `src/config.example.h` ל-`src/config.h` וממלאים: שם וסיסמה של ה-WiFi (אפשר כמה, למשל הבית ונקודה חמה בטלפון), כתובת השרת, ו-`DEVICE_KEY`.
4. מחברים את השעון ב-USB ולוחצים **Upload** (החץ בשורה התחתונה).

מהשורה:
```bash
cd watch && pio run -t upload
```
הבנייה הראשונה מורידה בערך 1GB של כלים ולוקחת כמה דקות.

## הערות
- WiFi בלבד, בתדר 2.4GHz. מחוץ לבית השעון מתחבר לנקודה חמה בטלפון.
- סוללה: עם WiFi דלוק והמסך כבה אחרי 20 שניות, אמור להחזיק בערך יום. זו הערכה שעוד לא נמדדה. הטעינה ב-USB.
- ספירת הצעדים נעשית בחיישן BMA423 שבשעון. השרת מסכם צעדים לכל יום, גם אחרי הפעלה מחדש.
